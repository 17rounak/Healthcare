## 2. Implementation-verified results

The following components are verified correct by construction and by the test suite (`tests/test_privacy.py`), independently of whether the paper's DP utility values are matched. They are compared against the paper's RDP formula (not against a paper AUC target), and describe the mechanism whose utility is reported.

- **DP clipping** (client-update level): each client's local model update is L2-clipped at C = 1.0 before aggregation. Verified by `test_clipping_bounds_norm`.
- **DP noise addition**: isotropic Gaussian noise with standard deviation sigma * C is added to the released client-weighted aggregate of clipped updates. Verified by `test_dp_noise_scale_is_sigma_times_clip_norm`.
- **Mechanism/accountant consistency**: the noise scale sigma*C uses the same sigma as the RDP accountant (RDP(alpha) = alpha / (2 sigma^2) per round). The realized per-round privacy exactly matches the accounted value. Verified by `test_dp_noise_empirical_std_matches_accounting`.
- **DP epsilon reproduction**: all five epsilon values reproduce the paper within 0.5% (see section 1 reproduced results, dp_epsilon rows).

## 4. DP convention (explicit)

| parameter | value |
|---|---|
| clipping norm C | 1.0 |
| clipping level | client update (L2 norm of per-client delta) |
| noise target | released client-weighted aggregate of clipped deltas |
| noise std | sigma * C |
| delta | 1e-05 |
| rounds | 40 |
| composition | RDP (pure, no subsampling amplification) |
| silos (full participation) | 5 |
| sigma values | [0.1, 0.25, 0.5, 1.0, 2.0] |

Mechanism: each client computes a local model update (delta), L2-clips it to norm C, and the server computes the sample-weighted average of clipped deltas. Gaussian noise N(0, (sigma * C)^2 I) is added to this aggregate before application. The RDP accountant computes RDP(alpha) = alpha / (2 sigma^2) per round with full participation (K = 5, no subsampling amplification), composed over T = 40 rounds and converted to epsilon with delta = 1e-05. An implementation cannot choose a different sensitivity bound or noise scale for the accountant without breaking the per-round equality RDP = alpha / (2 sigma^2); this is the convention the paper's own formula implies, and the implementation realizes it exactly.

## 5. DP utility curve non-reproducibility

The DP-FedAvg privacy-utility curve could not be exactly reproduced. Diagnostic testing in `scripts/dp_diagnostic.py` evaluated four noise conventions for each sigma in {0.1, 0.25, 0.5, 1.0, 2.0}:

| convention | noise std on released aggregate | matches paper |
|---|---|---|
| A (current) | sigma * C | sigma = 2 (logistic only) |
| B | sigma * C / sqrt(K) (per-client noise) | none |
| C | sigma * C / sqrt(K) | none |
| D (pre-fix) | sigma * C / K | low sigma |

Result: no single convention reproduces the paper's entire DP utility curve. Convention D (the pre-fix convention) matched the paper at low sigma but was mathematically inconsistent with the RDP accountant -- the realized per-round RDP was K^2 = 25x the accounted value (it added K times less noise than the sigma the accountant assumed). Convention A is the only convention consistent with the paper's stated RDP formula; it matches the paper at sigma = 2 for logistic regression but produces lower utility at sigma <= 1 than the paper reports (see section 3). The implementation uses convention A and reports the resulting utilities without adjustment.

## 10. Notes on likely causes of any discrepancy

- The LR linear-model ceiling on this dataset with the stated 15 predictors and a 20% stratified holdout is ~0.70 AUC (confirmed independently with an unregularised sklearn logistic regression). Reported paper values (~0.729-0.732) are above that ceiling, suggesting the paper's evaluation convention (e.g. in-sample scoring or a specific split draw) or extra feature processing differs from what is described.
- DP epsilon values use the paper's stated RDP composition formula T*alpha/(2*sigma^2) + log(1/delta)/(alpha-1) minimized over alpha > 1 (analytic optimum a + 2*sqrt(a*b), a = T/(2*sigma^2), b = ln(1/delta)). Four of five sigmas match the paper within rounding; for sigma = 0.1 the exact minimum is 2303.5 vs the paper's 2315.1 (-0.5%). The paper's value equals the formula evaluated at alpha = 1.1 (2000*1.1 + 115.13 = 2315.13), indicating a coarse alpha grid in the paper's accountant; we report the exact minimum of the paper's own formula.
- Communication cost uses: every client uploads a float32 delta and downloads a float32 global-model copy each round, 40 rounds x 5 clients, counted in decimal megabytes (1 MB = 10^6 bytes) as in the paper.
- Secure aggregation is assumed but NOT cryptographically implemented; the sufficient-statistics aggregation is conceptually compatible with it.
- All silos derive from one cohort; genuine institutional variation is not fully reproduced.
